# TypeScript-Projekt: Kundenverwaltung

Projekt im Wahlpflichtfach _KI-gestützte Serverentwicklung_ (Prof. Zimmermann,
Hochschule Karlsruhe), Abgabe 26.11.2026.

REST-Appserver mit Hono (HTTP/2), Drizzle, PostgreSQL und Keycloak für die
Domäne _Kunde_ mit _Adresse_ (1:1) und _Bestellungen_ (1:N).

> Die vollständige Anleitung folgt mit fortschreitender Entwicklung.
